# Штрих!
Мобильная браузерная игра по механике «Худо-быстро»: рисование слов на время и вспоминание по пронумерованным рисункам. Собственная реализация и оформление, без копирования исходного кода и ресурсов оригинала.

Откройте index.html или разместите каталог на статическом хостинге. Для GitHub Pages включите Settings → Pages → Source → GitHub Actions. Публикация запускается при push в main.

Возможности: три режима для игры через Discord, от 1 до 100 рисунков, время от 0,5 до 300 секунд с шагом 0,5, ручной ввод и быстрые варианты, таймер, русская озвучка через SpeechSynthesis, мышь/палец/стилус, ластик, отмена, пауза при скрытии страницы, локальное сохранение, ответы, личный счёт, PNG и печать сетки.

Одновременно рисует один художник; остальные смотрят его экран и отвечают голосом в Discord. Роль передаётся между раундами: следующий художник открывает сайт у себя и включает свою демонстрацию. Озвучка зависит от браузера. Раунды хранятся только в localStorage этого устройства. В приватном режиме сохранение может быть недоступно. Шрифт Manrope загружается из Google Fonts; при отсутствии сети используется системный шрифт. На iOS скачанный PNG может открыться для дальнейшего сохранения через меню «Поделиться».

## Слова и разнообразие

1539 заданий в 12 темах. Новые задания — конкретные предметы, животные и короткие сцены, которые можно изобразить рисунком. Неясные формулировки исправлены или убраны.

Выбор равномерно чередует доступные темы внутри раунда. История `stroke.word-history.v1` хранит использованные слова до исчерпания всего словаря; после перезагрузки продолжается тот же цикл. При переходе к новому циклу исключаются дубли внутри раунда, а последние 100 заданий откладываются, если есть альтернативы. При обновлении история учитывает последний сохранённый раунд. Добавленные в словарь слова автоматически попадают в доступный запас.

История относится к одному браузеру/устройству. Очистка данных сайта сбрасывает её. Если localStorage недоступен, история работает в памяти до перезагрузки. Одновременная игра в нескольких вкладках не синхронизируется.

Проверка алгоритма: `node tests/word-picker.cjs`.

## Режимы для Discord

- **Запомни** (базовый): друзья видят диктовку и рисунки. После раунда спрашивают художника по номерам, а он вспоминает слова. За верный ответ — 1 очко.
- **Угадай**: перед каждым словом художник вручную выключает демонстрацию в Discord, открывает слово, скрывает его кнопкой и снова включает трансляцию. Озвучка принудительно отключена. По таймеру холст остаётся на месте, ответ открывается вручную; «Угадали» и «Пас» записывают результат и открывают подготовку следующего слова. При восстановлении незавершённого рисунка снова показывается безопасный экран подготовки. Рекомендуем 30–60 секунд.
- **История**: общий рисунок накапливается от этапа к этапу. Зрители голосом предлагают сюжет. Сохраняются независимые снимки этапов; очки не считаются. Рекомендуем 15–30 секунд.

Сайт не управляет Discord и не распознаёт состояние трансляции. Секретное слово видно на том же экране: художник обязан остановить демонстрацию до его открытия. Отдельного приватного экрана, онлайн-комнаты и синхронизации устройств нет. Старые режимы `tt` и `classic` при восстановлении открываются как базовый режим.

Проверка режимов и безопасных переходов: `node tests/modes.cjs` (модель DOM и Canvas; без проверки на реальном телефоне).
