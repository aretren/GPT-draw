# Штрих!
Мобильная браузерная игра по механике «Худо-быстро»: рисование слов на время и вспоминание по пронумерованным рисункам. Собственная реализация и оформление, без копирования исходного кода и ресурсов оригинала.

Откройте index.html или разместите каталог на статическом хостинге. Для GitHub Pages включите Settings → Pages → Source → GitHub Actions. Публикация запускается при push в main.

Возможности: два варианта правил, от 1 до 100 рисунков, время от 0,5 до 300 секунд с шагом 0,5, ручной ввод и быстрые варианты, таймер, русская озвучка через SpeechSynthesis, мышь/палец/стилус, ластик, отмена, пауза при скрытии страницы, локальное сохранение, ответы, личный счёт, PNG и печать сетки.

В «Классике» каждый телефон получает независимые слова: общей онлайн-комнаты и синхронной диктовки нет. Очки компании считаются вручную; отметки на листе — личный счёт. Озвучка зависит от браузера. Раунды хранятся только в localStorage этого устройства. В приватном режиме сохранение может быть недоступно. Шрифт Manrope загружается из Google Fonts; при отсутствии сети используется системный шрифт. На iOS скачанный PNG может открыться для дальнейшего сохранения через меню «Поделиться».
